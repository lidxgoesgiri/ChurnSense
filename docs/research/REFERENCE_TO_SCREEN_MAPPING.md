# Peta referensi web → screen dan komponen ChurnSense

Tanggal: **31 Oktober 2026, Asia/Jakarta**. Root implementasi: `C:\Churn\loop-analytics`.

## Aturan pembacaan

Route halaman aktual hanya **`/`** dan **`/dashboard`**. Login adalah modal pada landing. Manual/CSV, hasil, history, retention table, comparison, insight, chat, command palette, serta model selector adalah section/state/overlay, bukan route baru.

`R01–R11` merujuk [WEB_DESIGN_REFERENCES.md](WEB_DESIGN_REFERENCES.md). Sumber telah diperiksa sebagai konten/IA/dokumentasi publik. **Current visual layout, actual motion, responsive screenshots, dan pixel measurements referensi belum diverifikasi.** Semua layout, ukuran, reflow, dan state di kolom adaptasi adalah **proposed untuk ChurnSense**, bukan deskripsi visual situs referensi.

Istilah kemiripan:

- **Interaction match:** ambil kontrak tindakan dan feedback, sesuaikan perilaku web serta fitur ChurnSense.
- **Structural adaptation:** ambil urutan informasi/anatomy yang terdokumentasi. Ini dapat ditingkatkan menjadi close structural match setelah section visual benar-benar diinspeksi.
- **Typographic inspiration:** ambil pembagian peran/hierarchy; font, warna dan brand tetap ChurnSense.

Kompleksitas S/M/L adalah estimasi perubahan UI, bukan estimasi jam. Risiko data/auth tidak disederhanakan menjadi polish.

## Target ukuran ChurnSense — proposal, bukan hasil ukur referensi

Sumber ukuran final adalah [design system](../design/CHURN_DESIGN_SYSTEM.md) dan [screen blueprints](../design/CHURN_SCREEN_BLUEPRINTS.md); nilai berikut menjelaskan maksud pemetaan:

- Container dashboard target maksimal 1.280 CSS px; page gutter 16 px mobile, 24 px tablet, 32 px desktop. Hindari forced minimum width pada page.
- Workbench ≥1.200 px jika available width cukup: input rail 360 px + minmax(0,1fr) hasil, gap24; selain itu stack. Chart full-width setelah workbench, kemudian section AI. AI bukan contextual sidebar pada final layout. Tidak ada sidebar kosong.
- Input/action utama minimal sekitar 44 CSS px pada compact view; teks form 16 px. Metadata boleh 12–13 px bila terbaca dan bukan satu-satunya instruksi.
- Motion feedback 120–180 ms, overlay maksimal180 ms mengikuti design system. Tidak ada durasi yang diukur dari referensi. Reduced-motion mempertahankan feedback tanpa transform besar atau animasi chart panjang.
- Border/surface opaque mendahulukan kontras. Blur/glow tidak menjadi layer default pada setiap card.

## Kontrak data yang membatasi replika

1. **Snapshot, bukan cohort.** `SavedProject` menyimpan `id`, `projectName`, `createdAt`, dan metrics. Timestamp penyimpanan tidak membuktikan bulan/periode data input. Tidak ada inventaris customer/events untuk drill-down ala ChartMogul/Stripe.
2. **Rasio memiliki arah.** Churn lebih rendah baik, retention lebih tinggi baik. Gunakan units dan penjelasan tekstual; jangan menghitung ulang metrik di komponen demi style.
3. **Automatic save berbeda dari export.** Manual analyze mencoba save best-effort; jangan mengubahnya menjadi workflow save manual tanpa keputusan produk. Kegagalan simpan tidak membuat hasil hitung invalid.
4. **AI tidak selalu provider.** Empty/error/fallback harus sesuai contract. Meniru kemasan AI referensi tidak mengizinkan klaim prediction atau data access yang belum tersedia.
5. **History dapat terpotong.** Parent fetch saat ini meminta `/api/projects` tanpa paging loop; bedakan loaded data versus total. Jangan menggambarkan chart/history/CSV sebagai lengkap sebelum cakupan diselesaikan.
6. **Auth bukan elemen dekoratif.** Existing login mengizinkan instant session; pending emailed magic link hanya jika flag verification dan provider aktif. Pertahankan expiry/CSRF/session handling. Tidak ada OTP entry atau resend endpoint terpisah yang ditemukan; re-request conditional menggunakan submit existing. Desain modal mengikuti flow.

## Acceptance untuk pemetaan

- Setiap perubahan punya route/section aktual, existing file yang diperiksa ulang, satu tujuan UX, dan state yang dapat diuji.
- Seluruh aksi di UI dapat diselesaikan dengan pointer dan keyboard; tidak ada CTA/menu/filter fiktif untuk mengisi layout.
- Responsive memelihara prioritas informasi; table scroll terlokalisasi dan tidak membuat body horizontal overflow.
- Data asli tetap source of truth; contoh landing diberi label; tidak ada fabricated trend, benchmark, cohort, forecast, atau performance result.
- Catat visual source yang belum dapat diinspeksi sebagai gap. Tidak ada screenshot referensi yang saat ini tersedia dalam deliverable ini.
